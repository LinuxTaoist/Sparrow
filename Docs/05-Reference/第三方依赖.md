# 第三方依赖

## 当前有效依赖

### SQLite
- 版本：3.45.3
- 目录：`3rdParty/sqlite/`
- 作用：数据库能力，供 `SqliteAdapter` 使用。
- 产物：`libsqlite3.a`，位于 `3rdParty/sqlite/lib/{platform}/`
- 代码位置：`3rdAdapter/SqliteAdapter.cpp`

### GoogleTest
- 版本：1.12.1
- 目录：`3rdParty/googletest/`
- 作用：单元测试与基准测试。
- 产物：`libgtest.a`、`libgtest_main.a`
- 使用条件：`BUILD_TESTCASE=ON`

### curl
- 版本：8.10.1
- 目录：`3rdParty/curl/`
- 作用：HTTP/HTTPS 客户端能力。
- 产物：`libcurl.a`，位于 `3rdParty/curl/lib/{platform}/`
- 使用条件：`BUILD_CURL=ON`
- 构建方式：同 sqlite/googletest 一样，若库不存在则自动调用 `3rdParty/curl/build.sh` 通过源码交叉编译并输出到平台目录。

### GDB
- 版本：10.2
- 目录：`3rdParty/gdb/`
- 作用：在目标设备上分析 core dump。
- 产物：`gdb`，位于 `3rdParty/gdb/bin/{platform}/`，并复制到构建输出的 `Bin/`。
- 使用条件：`BUILD_GDB=ON`
- 构建方式：若目标平台的 gdb 不存在，自动调用 `3rdParty/gdb/build.sh` 交叉编译源码。

### i2c-tools
- 版本：4.4
- 目录：`3rdParty/i2c-tools/`
- 作用：在目标设备上扫描并读写 I2C 设备，辅助硬件调试。
- 产物：`i2cdetect`、`i2cdump`、`i2cget`、`i2cset`、`i2ctransfer`，位于 `3rdParty/i2c-tools/bin/{platform}/`，并复制到构建输出的 `Bin/`。
- 使用条件：`BUILD_I2C_TOOLS=ON`
- 构建方式：若目标平台工具不存在，自动调用 `3rdParty/i2c-tools/build.sh` 交叉编译源码；工具静态链接 i2c-tools 自带的 libi2c，不额外安装库和头文件。

### strace
- 版本：7.3
- 目录：`3rdParty/strace/`
- 作用：跟踪目标设备进程的系统调用、信号和进程状态，辅助排查运行时问题。
- 产物：`strace`，位于 `3rdParty/strace/bin/{platform}/`，并复制到构建输出的 `Bin/`。
- 使用条件：`BUILD_STRACE=ON`
- 构建方式：若目标平台的 strace 不存在，自动调用 `3rdParty/strace/build.sh` 交叉编译源码；禁用 mpers 以避免额外 ABI 编译器依赖。

### cJSON
- 版本：1.7.18
- 目录：`Util/` 和 `UtilModules/CodecX/`
- 作用：JSON 解析与生成。
- 代码位置：`Util/cJSON.c`、`Util/cJSON.h`、`UtilModules/CodecX/cJSON.c`、`UtilModules/CodecX/cJSON.h`

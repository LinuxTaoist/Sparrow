# 第三方依赖

## 当前有效依赖

### SQLite
- 版本：3.45.3
- 目录：`3rdParty/sqlite/`
- 作用：数据库能力，供 `SqliteAdapter` 使用。
- 产物：`libsqlite3.a`，位于 `3rdParty/sqlite/lib/{platform}/`
- 代码位置：`3rdAdapter/SqliteAdapter.cpp`

### GoogleTest
- 版本：1.12.1
- 目录：`3rdParty/googletest/`
- 作用：单元测试与基准测试。
- 产物：`libgtest.a`、`libgtest_main.a`
- 使用条件：`BUILD_TESTCASE=ON`

### curl
- 版本：8.10.1
- 目录：`3rdParty/curl/`
- 作用：HTTP/HTTPS 客户端能力。
- 产物：`libcurl.a`，位于 `3rdParty/curl/lib/{platform}/`
- 使用条件：`BUILD_CURL=ON`
- 构建方式：同 sqlite/googletest 一样，若库不存在则自动调用 `3rdParty/curl/build.sh` 通过源码交叉编译并输出到平台目录。

### cJSON
- 版本：1.7.18
- 目录：`Util/` 和 `UtilModules/CodecX/`
- 作用：JSON 解析与生成。
- 代码位置：`Util/cJSON.c`、`Util/cJSON.h`、`UtilModules/CodecX/cJSON.c`、`UtilModules/CodecX/cJSON.h`

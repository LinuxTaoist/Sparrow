# 功能概览

当前工程中已实现的功能与对应文档索引，便于直接定位需要查阅的能力。

| 功能               | 说明                                                                 | 参考文档 |
| ------------------ | -------------------------------------------------------------------- | -------- |
| 事件驱动           | 基于 `Epoll` 处理 IO、消息回调与任务调度，适合高并发设备服务。       | 使用： [SprObserverWithMQueue](../02-Design/Core/SprObserverWithMQueue.md)、[SprObserverWithMQueueThread](../02-Design/Core/SprObserverWithMQueueThread.md) |
| 定时器             | 提供定时触发、周期调度和时间同步相关能力。                           | 实现： [TimeManager](../02-Design/Components/Basics/TimeManager.md) |
| 内部组件通信       | 提供模块间消息对象、消息队列接入与消息中转能力。                     | 使用： [SprMsg](../02-Design/Core/SprMsg.md)、[SprObserverWithMQueue](../02-Design/Core/SprObserverWithMQueue.md)、[SprObserverWithMQueueThread](../02-Design/Core/SprObserverWithMQueueThread.md)<br>实现： [MediatorSrv](../02-Design/Components/Basics/MediatorSrv.md) |
| 外部 RPC 接口封装  | 通过 PublicAPIs 封装跨进程调用和异步事件回调，对业务模块屏蔽底层通信细节。 | 使用： [Config](../02-Design/PublicAPIs/Config.md)、[Property](../02-Design/PublicAPIs/Property.md)、[PowerManagerInterface](../02-Design/PublicAPIs/PowerManagerInterface.md)<br>实现： [Binder](../02-Design/PrivateAPIs/Binder.md)、[Event](../02-Design/PrivateAPIs/Event.md)、[BinderManagerSrv](../02-Design/Components/Basics/BinderManagerSrv.md) |
| 服务管理           | 启动、监控、心跳、依赖顺序、异常重启和优雅退出。                     | 实现： [ServiceManagerSrv](../02-Design/Components/Basics/ServiceManagerSrv.md) |
| 配置管理           | 支持 default / factory / user 三级作用域、版本管理、持久化和备份。   | 使用： [Config](../02-Design/PublicAPIs/Config.md)<br>实现： [ConfigManagerSrv](../02-Design/Components/Basics/ConfigManagerSrv.md) |
| 属性管理           | 动态属性读写、持久化、日志联动、状态观测。                           | 使用： [Property](../02-Design/PublicAPIs/Property.md)<br>实现： [PropertiesSrv](../02-Design/Components/Basics/PropertiesSrv.md) |
| 日志与诊断         | 统一日志收集、等级过滤、落盘、轮转和调试入口。                       | 使用： [SprLog](../02-Design/3rdAdapter/SprLog.md)<br>实现： [LogManagerSrv](../02-Design/Components/Basics/LogManagerSrv.md) |
| 调试能力           | 调试消息、远程 shell、定时器联调、广播测试等开发排障能力。           | 使用： [DebugInterface](../02-Design/PrivateAPIs/DebugInterface.md)<br>实现： [DebugSrv](../02-Design/Components/Basics/DebugSrv.md) |
| 文件/目录监听      | 监控目录变更、文件事件和异步感知能力。                               | 实现： [SprDirWatch](../02-Design/Core/SprDirWatch.md) |
| 进程守护与恢复     | 服务进程启动、健康检测、异常重启与退出处理。                         | 实现： [ServiceManagerSrv](../02-Design/Components/Basics/ServiceManagerSrv.md) |
| 平台适配           | 将硬件和平台差异从业务逻辑中剥离，便于不同 Linux / 嵌入式平台移植。  | 使用： [系统架构](系统架构.md) |
| 测试用例           | 提供单元测试、功能验证和示例程序入口。                               | 使用： [TestCase/README.md](../../TestCase/README.md) |
| 示例程序           | 覆盖网络、消息、日志、数据库、HTTP、硬件接口等典型用法。             | 使用： [Examples/README.md](../../Examples/README.md) |

## 直接使用时的建议

- 需要看内部组件通信：优先看 [SprMsg](../02-Design/Core/SprMsg.md)、[SprObserverWithMQueue](../02-Design/Core/SprObserverWithMQueue.md) 与 [SprObserverWithMQueueThread](../02-Design/Core/SprObserverWithMQueueThread.md)
- 需要看外部 RPC 接口：优先看 [Config](../02-Design/PublicAPIs/Config.md)、[Property](../02-Design/PublicAPIs/Property.md) 与 [PowerManagerInterface](../02-Design/PublicAPIs/PowerManagerInterface.md)
- 需要看配置：优先看 [Config](../02-Design/PublicAPIs/Config.md)
- 需要看属性：优先看 [Property](../02-Design/PublicAPIs/Property.md)
- 需要看日志与调试：优先看 [SprLog](../02-Design/3rdAdapter/SprLog.md) 与 [DebugInterface](../02-Design/PrivateAPIs/DebugInterface.md)
- 需要看服务生命周期：优先看 [ServiceManagerSrv](../02-Design/Components/Basics/ServiceManagerSrv.md)
- 需要看示例代码：直接查看 [Examples/README.md](../../Examples/README.md)

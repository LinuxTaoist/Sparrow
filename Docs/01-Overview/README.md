## 项目定位

Sparrow 是一个面向 Linux / 嵌入式设备场景的 C++ 中间件框架，重点解决以下问题：

- 设备端服务之间的通信和解耦
- 事件驱动下的稳定运行与任务调度
- 日志、状态、属性和调试能力的统一管理
- 硬件与平台差异的适配与隔离
- 业务扩展时的工程结构清晰和可维护

Sparrow 是一个设备端基础中间件与服务运行平台，适合在其上扩展定制业务组件，并支持多种嵌入式 Linux 平台的适配与演进。

## 适用范围

更适合以下场景：

- 工业网关 / 边缘网关
- 数据采集终端 / 监测终端
- 车载控制器 / 智能终端
- 工业控制节点 / 自动化设备
- 嵌入式 Linux 设备平台

## 关键能力

- `Epoll` 事件驱动模型
- 模块化通信：Binder、消息队列、事件分发
- 进程/服务管理与稳定性能力
- 属性、日志和调试节点
- `Hardware/` 与 `Platform/` 分层适配
- 配合 `Components/`、`PublicAPIs/`、`PrivateAPIs/` 扩展业务

# 使用指南 - 定时器
[TOC]

## 概要
定时器功能是用于在指定的时间间隔内执行特定任务的机制。在程序中，定时器通常用于实现：
- 周期性任务
- 延时任务
- 定时触发事件

## 使用代码说明
定时器的使用比较简单，只需要调用注册定时器接口，间隔，传入消息ID，生命周期即可。参考代码 [TestSprTimerManager.cc](../UserManual/../../TestCase/Internal/Components/TestSprTimerManager.cc)
1. 注册定时器
```C++
RegisterTimer(0, 200, SIG_ID_TEST_MODULE_200MS_TIMER_EVENT, 5);   // 注册定时器 SIG_ID_DEBUG_TIMER_TEST_1S，间隔1s，生命周期为0（即一直运行）
UnregisterTimer(SIG_ID_TEST_MODULE_200MS_TIMER_EVENT);                // 取消定时器 SIG_ID_DEBUG_TIMER_TEST_1S
```
2. 监听定时器消息
```c++
int32_t TestModule::ProcessMsg(const SprMsg& msg)
{
    ...
    switch (msg.GetMsgId()) {
        case SIG_ID_TEST_MODULE_200MS_TIMER_EVENT: {
            ...
            break;
        }
        ....
        default:
            break;
    }

    ...
    return 0;
}
```

## 原理说明
微服务中，已经实现组件 [SprTimerManager](../UserManual/../../Components/Basics/SparrowSrv/SprTimerManager.h) ，该组件负责其他组件的定时器注册、注销、触发、定时器分发等操作。

### 封装
- SprTimerManager: 定时器管理器，负责定时器的注册、注销、触发、定时器分发等。
- SprTimer: 定时器对象，负责定时器的生命周期管理。
- SprSystemTimer: 原生定时器接口封装。
